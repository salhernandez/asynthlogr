# Vault layout

basic-memory-managed — REQUIRED, external to any repo. Every file in
this tree is a basic-memory note, written through basic-memory's MCP
tools by whichever agent owns it — never a plain filesystem write.
(Obsidian, if used, is just a viewer on top of the same directory
basic-memory manages — it is not itself a requirement.)

`asynthlogr` is registered as its own basic-memory **project** — it
does not get an arbitrary directory of its own choosing. Its project
directory is `<basic-memory-root>/asynthlogr`, where `<basic-memory-root>`
is either `--basic-memory-root` passed to `install.sh`, or
basic-memory's own default (`~/basic-memory`) if that flag was
omitted. Everything below is rooted at that project directory —
`<vault-root>` in this document and elsewhere in this repo always
means `<basic-memory-root>/asynthlogr`, which is also the exact value
stored as `basic_memory_dir` in `.claude/asynthlogr.config.json`.

```
<vault-root>/
  failed-writes.log                              # single dead-letter log, flat, across all repos — plain file, NOT a basic-memory note

  <repo-name>/
    <thread-name>/
      <thread-name>.md                            # distilled decision + info entries, chronological, mixed types
      agent-use-tracking.md                       # thread-level: current step + step-transition log
      subagents/
        <run_id>_<subagent_name>-<topic_slug>/
          agent-use-tracking.md                    # this run's live status, written by the subagent itself
          output.md                                 # this run's distilled record, written by decision-logger

  reports/
    <YYYY-MM-DD>.md                                 # daily report output — NOT YET DESIGNED, see docs/open-items.md
```

`run_id` format: ISO 8601 timestamp with `:` and `.` replaced by `-`
(e.g. `2026-09-26T11-14-51`).

`topic_slug` and `thread-name` format: short kebab-case, generated by
the orchestrator (never by `decision-logger`, to avoid the naming race
— see `docs/architecture.md`).
